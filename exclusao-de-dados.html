Solicitação de Exclusão de Dados

Última atualização: 2 de novembro de 2026

Se você utilizou o Bot Zap Tec e deseja solicitar a exclusão de informações pessoais associadas ao seu número de WhatsApp, siga as instruções abaixo.

Como solicitar

  1. Envie um e-mail para wagnerxsalles@hotmail.com.
  2. Use o assunto “Solicitação de exclusão de dados – Bot Zap Tec”.
  3. Informe o número de telefone utilizado para conversar com o bot, incluindo o código do país e DDD.
  4. Descreva que deseja excluir os dados associados a esse número.

O que acontece depois

A solicitação será analisada e poderemos pedir informações razoáveis para confirmar que ela foi feita pelo titular dos dados. Após a confirmação, os dados pessoais associados serão excluídos dos registros ativos da aplicação, salvo quando a conservação for necessária para cumprir obrigação legal ou proteger direitos. Se alguma informação precisar ser mantida por esse motivo, isso será explicado na resposta.

Prazo e contato

Confirmaremos o recebimento e responderemos pelo e-mail utilizado na solicitação, dentro de prazo razoável e conforme a legislação aplicável. Não envie senhas, códigos de verificação ou tokens de acesso.

Esta página trata dos dados mantidos pelo projeto Bot Zap Tec. Ela não substitui os procedimentos próprios da Meta ou do WhatsApp para dados tratados diretamente por essas plataformas.
